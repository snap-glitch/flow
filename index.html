Collegare Supabase

Il tool è collegato a Supabase. Dati in pm_items, storico in pm_events, archivio in pm_directory, file nel bucket attachments. Utenti in Authentication → Users, email definite in USER_EMAILS in cima allo script. Schema di base:

create table if not exists pm_items (
  id text primary key,
  col text not null,
  data jsonb not null,
  updated_at timestamptz default now()
);
alter table pm_items enable row level security;
create policy "team_rw" on pm_items
  for all to authenticated using (true) with check (true);
alter publication supabase_realtime add table pm_items;

Poi crea gli utenti del team in Authentication → Users.
